动效原则

  • 弹性反馈：按钮点击用 translateY(2px) + 阴影收缩，模拟物理按下
  • 缓动曲线：所有过渡用 cubic-bezier(.4, 0, .2, 1) 或 ease-out，禁用linear
  • 持续时间：短反馈 150ms / 页面切换 300ms / 庆祝动画 500ms
  • 层级：toast 400ms slide-down，模态弹窗 200ms scale + fade
  • 失败/通关：emoji 弹性放大 scale(0→1.2→1)，数字 88px pop
  • 接近 50%：切割线右端变金 + 持续 1.2s pulse

Cocos 实现 Checklist

  • 所有颜色 / 字号 / 圆角都进 全局 CSS 变量，Cocos 同步进 resources/configs/design.json
  • 按钮阴影：Cocos 用 box-shadow 等价物 UITransform + Shadow 组件
  • emoji 在 Cocos 中换成预制 SVG 图标（避免字体兼容性）
  • 切割线用 Graphics 组件绘制，不用 Sprite 帧
  • 4 档情绪色映射 function getTier(pct) 集中维护
  • 动效用 tween，不用 Animation Editor（MVP 阶段）
